# 方法

Video–Time Priors for EEG–fNIRS Emotion Regression on Familiar Videos。

任务是在已知视频的每个对齐时间点，预测新观众的效价与唤醒度。两个目标均使用原始 **[1, 255]** 标度。

## 视频—时间先验

对每个视频、时间点和目标维度，取可用训练参与者标签的中位数，再在视频边界内进行**半径为 3 的滑动平均**。

```text
原始先验(视频, 秒) = 训练参与者标签的中位数
平滑先验(视频, 秒) = 视频内滑动平均(原始先验, 半径=3)
```

内部评估仅用每折的训练参与者重建先验；外部队列评估使用全部 24 名开发集参与者。先验构建后只需根据视频身份与时间查表，无需采集新观众的生理信号。

## 生理分支

使用对应的五秒静息基线中心化信号，并将 EEG 重采样到 200 Hz。EEG 特征包含 1–45 Hz 六个频带的相对对数功率、微分熵，以及 Hjorth 活动度、移动度和复杂度。

每个 fNIRS 通道包含六种输入：HbO、HbR、HbT，以及 780、805、830 nm 吸光度，分别提取均值、标准差、斜率、偏度和峰度。

| 组成 | 配置 |
| --- | --- |
| 时间上下文 | 前一秒、当前秒和后一秒；边界采用边缘填充 |
| EEG 输入 | 64 通道 × 45 特征 |
| fNIRS 输入 | 51 通道 × 90 特征 |
| 图编码器 | 可学习邻接矩阵；恒等、一阶和二阶传播 |
| 跨模态注意力 | 双向四头；折模型使用 32 维通道嵌入 |
| 回归 | 均值 / 最大池化、多层回归器、sigmoid 输出 |
| 折模型训练 | MSE + 0.01 × 对比对齐损失；dropout 0.7；AdamW；基于验证 MSE 早停 |

特征标准化统计量来自相应的训练参与者。训练标签缩放至 `[0, 1]`，预测再还原至 `[1, 255]`。

## 固定融合

```text
prediction = [0.99, 0.92] * video_time_prior
           + [0.01, 0.08] * eeg_fnirs_prediction
# 目标顺序：[效价, 唤醒度]
```

外部队列保持相同权重。该配置不使用静息输出校准。

## 信息边界

先验不使用留出参与者的标签，生理分支使用新观众的信号。后一秒上下文使预测属于**离线方法**；当前没有针对 fNIRS 血流动力学延迟进行时滞补偿。

检查点与权重选择未完全嵌套。实验只评估一种生理架构，未隔离 EEG、fNIRS、图结构和注意力的贡献，因此不能据此证明或排除任一模态具有独立情感信息。
