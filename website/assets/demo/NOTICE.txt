Public Training/Validation Data

Dataset-card revision: 776227330531a705a55bfd52f74ea5b537f89e75

sample.vtp-input.json is an adapted 30-second excerpt (test_1, video 1,
seconds 0-29). Changes: baseline correction, feature extraction and
previous/current/next-second context using the Vtp-Emotion feature pipeline.
This includes derived physiological features, not raw signals, participant
metadata, or individual emotion annotations. This is a development-set
example and must not be presented as independent held-out evaluation.

model.vtp-model.json contains the Vtp-Emotion six-model ONNX ensemble,
checkpoint-specific standardization, and video-time prior learned from
MER-PS training/validation data. Source implementation:
https://github.com/rudykon/Vtp-Emotion
