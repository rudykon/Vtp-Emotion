# 仓库发布审计

审计日期：2026-07-24

## 结论

当前 GitHub 目标仓库为私人仓库。论文源文件、可编辑矢量图、绘图代码和不含逐样本真实标签的汇总表可以提交；账户令牌、原始 EEG/fNIRS 数据、特征缓存、检查点、运行产物以及受限参与者不重叠队列的逐样本标签必须保留在本地。

## 已确认的版本控制边界

- `*_token.json`、`.env`、密钥文件均由 `.gitignore` 排除。
- `data/` 中的原始研究数据与下载数据、`checkpoints/` 和 `artifacts/` 均不纳入版本控制。
- LaTeX 辅助文件、Python 缓存、PNG/TIFF 预览和本地环境均被排除。
- 逐样本外部真实标签、预测及试验级标签摘要仅用于本地图件重画，已加入 `.gitignore`。
- 论文中提交的 PDF/SVG 图件只表达汇总或可视化结果，不携带账户凭据或本地绝对路径。

## 数据与表述边界

4 名评估参与者与 24 名开发参与者互不重叠，但使用相同的 15 个视频和同类采集流程。因此，该队列适合表述为“参与者不重叠留出队列”，不能据此声称不同站点、设备或独立研究条件下的外部验证。

逐秒观测具有参与者内和视频内相关性。当前图件中的秒级密度、视频分层和时间分层只承担描述性诊断，不应被解释为 6,143 次独立重复。
