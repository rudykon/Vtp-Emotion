# 连续情感回归的来源显式分析方法

## 科学问题

24 名开发集被试观看了相同的 15 个时间对齐视频。因此，被试留出划分虽然隔离了观看者，却仍保留刺激标识和时间戳。本研究关注两个问题：观测到的预测准确性有多少可由共享刺激坐标解释，以及 EEG--fNIRS 生理预测器还能提供多少额外信息。

研究的一句话论点是：在重复且时间对齐的刺激协议中，折内视频—时间先验解释了被试留出情感回归中的主要总体增益，而生理分支只提供较小且分布不均匀的互补残差。

## 信息来源

### 折内视频—时间先验

在每个外层折中，首先按照视频和秒级时刻汇总训练被试的标签，并取各坐标上的中位数，得到群体情感轨迹。随后仅在同一视频内部采用半径为 3 的时间窗口进行平滑。留出被试的标签不会参与其对应先验的构建。

```text
prior(video, time) = median_training_participants(label)
```

这一设计显式测量仅凭视频标识和时间戳可以获得的预测信息，同时避免将留出被试标签泄漏到先验中。

### EEG--fNIRS 生理分支

EEG 和 fNIRS 信号首先使用相应试验的五秒静息片段进行中心化。对于每个一秒 EEG 窗口，管线提取六个频带的相对对数功率和微分熵，以及 Hjorth 活动度、移动性和复杂度。拼接前一秒、当前秒和后一秒的上下文后，每个 EEG 通道包含 45 个特征。

对于每个 fNIRS 通道及其六类信号，管线计算均值、标准差、斜率、偏度和峰度。经过三秒上下文拼接后，每个通道包含 90 个特征。两种模态分别由图编码器建模，并通过双向跨模态注意力交换信息，最后输入回归头。五个按被试分组训练的检查点用于生成折外生理预测。

### 固定融合

描述性融合采用以下形式：

```text
prediction = [0.99, 0.92] * video_time_prior
           + [0.01, 0.08] * physiological_prediction
```

两个维度依次对应效价和唤醒度。当前来源分解不使用静息输出校准，其收缩向量为 `[0.0, 0.0]`。由于固定权重没有在有记录的嵌套验证中重新选择，融合增量只作描述性解释。

## 五折被试留出协议

全部开发集被试被划分为五折。每个外层折依次执行以下步骤：

1. 仅使用训练被试重新构建视频—时间先验；
2. 仅使用训练被试估计生理特征的标准化参数；
3. 使用与该折对应的生理检查点预测留出被试；
4. 在完全相同的样本键上比较生理分支、视频—时间先验和固定融合。

五折预测与真实标签在计算指标前拼接，并据此计算按样本汇总的平均绝对误差（MAE）。该协议衡量新观看者对已见视频的情感预测，不衡量向未见刺激的迁移能力。

| 信息来源 | 总体 MAE | 效价 MAE | 唤醒度 MAE |
| --- | ---: | ---: | ---: |
| 生理分支 | 47.3509 | 51.3475 | 43.3543 |
| 视频—时间先验 | 29.0633 | 26.6681 | 31.4585 |
| 固定融合 | 29.0146 | 26.6642 | 31.3651 |

相对于单独使用生理分支，视频—时间先验使总体 MAE 降低 18.2876。固定融合在先验基础上进一步降低 0.0487。从生理分支到固定融合的总误差降幅中，约 99.7% 已由共享刺激先验实现。

## 外部被试独立评估

外部数据包含 4 名与开发集不重叠的观看者、60 次试验和 6,143 个秒级目标。评估管线将预测与评分分离：先验构建、检查点训练和预测阶段不读取外部目标；预测完成后，评分阶段才依据 `sample_id` 将整数预测与本地目标连接。

五种来源变体为：

1. 全局常数：开发集全部标签的二维中位数；
2. 视频身份先验：每个视频一个固定二维中位数，不使用时间坐标；
3. 视频—时间先验：全部开发被试构建的视频内秒级中位数轨迹；
4. 生理分支：一个固定划分检查点与五个被试分组折检查点组成的六模型集成；
5. 固定融合：使用 `[0.99, 0.92]` 融合视频—时间先验与生理分支。

| 变体 | 总体 MAE | 效价 MAE | 唤醒度 MAE | 总体 MSE |
| --- | ---: | ---: | ---: | ---: |
| 全局常数 | 44.3296 | 47.4622 | 41.1971 | 2861.1141 |
| 视频身份先验 | 33.3627 | 32.5567 | 34.1686 | 1933.0132 |
| 视频—时间先验 | 28.0410 | 25.3436 | 30.7384 | 1484.6883 |
| 生理分支 | 42.7486 | 45.2852 | 40.2119 | 2729.3677 |
| 固定融合 | **27.7246** | **25.1970** | **30.2522** | **1440.5642** |

外部评估还保留逐样本成对预测，并按被试、视频和十个归一化视频时间区间汇总残差：

- 固定融合在 4 名被试中的 3 名上改善，变化范围为恶化 0.0622 至改善 0.6938；
- 固定融合在 15 个视频中的 9 个上改善，变化范围为恶化 0.2971 至改善 1.3105；
- 第一个归一化时间区间中，视频身份先验 MAE 为 45.53，视频—时间先验为 13.40；
- 最后五个时间区间中，视频身份先验的 MAE 均略低于视频—时间先验。

这些分层结果说明，总体有利的融合增量和时间增量都不是均匀效应。由于只有 4 个被试聚类，当前不进行秒级伪重复显著性检验。

## 科学解释与结论边界

结果揭示了重复刺激连续情感回归中的来源混淆：较低的被试留出误差可能主要来自由视频和时间索引的群体情感轨迹，而不一定主要来自个体生理信号。该结果不能证明 EEG 或 fNIRS 缺乏情感信息，也不能外推到未见视频。

若要对生理信息的独立贡献作出更强结论，后续实验需要同时报告仅刺激基线，采用被试×刺激交叉留出设计，保留各组件的成对残差，并使用尊重被试和视频聚类结构的不确定性估计。

## 复现命令

运行五折来源分解：

```bash
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 \
  .venv/bin/python scripts/evaluate.py --blend-checkpoints
```

运行外部被试独立评估，并把紧凑图件源数据写入论文目录：

```bash
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 \
  .venv/bin/python scripts/evaluate_external.py \
  --source-data-dir paper/figures
```

评估产物位于 `artifacts/external_evaluation/`，包括数据审计、总体指标、被试/视频/时间分层指标和逐样本成对预测。生成论文图件：

```bash
.venv/bin/python paper/figures/make_external_figures.py
```

模型包仅作为完整数据训练后的推理与复现产物。论文中的被试留出科学结论来自五折来源分解，外部异质性结论来自本地外部数据的成对评估。
